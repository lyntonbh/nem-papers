Part 2Building blocks: the networks, the trees, and the pre-processing tricks

Every model in the papers is assembled from the pieces below. The pieces are grouped as: how a network is trained at all; the three classic shapes (dense, convolutional, recurrent); the odd ones (autoencoders, random-weight networks); the non-neural baselines; the hyperparameter search; and the "decompose first" pre-processing family.

A neuron, a layer, a dense network (MLP, DNN, BPNN)

In one sentence. A neuron multiplies each input by a weight, adds them up with a bias, and passes the sum through a simple bend (an activation function); a layer is many neurons on the same inputs; a dense network stacks layers so bends compose into any curve.

Left: one neuron. Right: three inputs, a hidden layer of four, one output. "MLP", "DNN" and "BPNN" (back-propagation neural network) all mean this shape; DNN usually implies more than two hidden layers.

Training: loss, gradient descent, epochs, learning rate, Adam

In one sentence. Training measures how wrong the network is with a loss function, computes which direction each weight should move to reduce it (the gradient, by back-propagation), and takes a small step that way, over and over.

One pass through the training set is an epoch; Sinclair trains for up to 20. The learning rate is the step size (2 × 10−4 in Sinclair): too big and training bounces, too small and it crawls. Adam is the standard optimiser; it keeps a running average of past gradients so each weight gets its own adaptive step. Batch size (128 in Sinclair) is how many samples are averaged per step. Reduce-on-plateau halves the learning rate when validation loss stops improving; early stopping ends training when it has not improved for several epochs (patience 5 in Sinclair) to avoid overfitting.

Loss as a landscape over one weight. Each step moves downhill by learning-rate × slope. Adam scales the step per weight.

Loss functions: MSE, MAE, Huber, and quantile (pinball)

In one sentence. The loss decides what "wrong" costs; squared error makes the model chase spikes hard, absolute error makes it aim for the median and ignore them, Huber is squared near zero and absolute far away, and quantile loss tilts the penalty so the model learns a specific percentile.

Loss against the size of the miss. Huber (δ = 0.8 in Sinclair, on scaled data) follows MSE inside ±δ and MAE outside, so a A$10,000 spike miss does not dominate training the way it would under MSE.
Worked example: quantile (pinball) loss, used by the Temporal Fusion Transformer

Training three such heads (q = 0.1, 0.5, 0.9) gives a band, which is how TFT produces its interval.

Overfitting and the standard defences: dropout, layer normalisation, residual connections

In one sentence. Overfitting is memorising the training set's noise; dropout randomly switches neurons off during training so no single path can be relied on, layer normalisation rescales each sample's activations so training is stable, and a residual connection adds a layer's input straight to its output so the layer only has to learn a correction.

Left: dropout knocks out a random 5 % (Sinclair) to 30 % of units each step. Middle: LayerNorm subtracts the mean and divides by the standard deviation across a sample's features. Right: the residual "skip" wire around a block; "pre-LN" (Sinclair's Figure 3) normalises before the block instead of after, which trains more stably in deep stacks.
Common confusion. Layer normalisation normalises across the features of one sample. Batch normalisation normalises each feature across the samples in a batch. Transformers use the first because sequences in a batch have different lengths and statistics.

Scaling inputs: standard, robust, quantile, and RevIN

In one sentence. Networks train badly on raw dollars, so every input is rescaled to a similar range; the choice matters for a series with a A$−1,000 to A$17,500 range and a median around A$100.

Standard scaling subtracts the mean and divides by the standard deviation; one spike inflates the standard deviation and squashes all the ordinary prices into a narrow band. Robust scaling uses the median and inter-quartile range instead. Quantile transformer scaling (Sinclair's choice) maps every value to its rank on a 0 to 1 scale and then to a normal distribution, so A$100 and A$10,000 land at their percentiles and the spike stops dominating. RevIN (reversible instance normalisation, used inside PatchTST) normalises each input window by its own mean and standard deviation and un-does it on the output, so the model sees "shape" not "level".

1-D convolutional network (CNN)

In one sentence. A small window of weights (a kernel or filter) slides along the series and at each position outputs the weighted sum of the values under it, so the same pattern detector is applied everywhere; many filters run in parallel, and stacking layers detects patterns of patterns.

Terms you will meet: kernel size (how many time steps a filter spans), stride (how far it jumps each move), padding (zeros added at the ends so the output is the same length), channels (number of filters, or number of input series), pooling (take the max or mean over small blocks to shorten the series and keep the strongest response), Conv1D (Keras's name for this layer). A TCN (temporal convolutional network) is a stack of causal, dilated 1-D convolutions that only look backwards; the companion page walks one through numerically.

The kernel (−1, 0, +1) slid along eight half-hourly prices. Each output is "price two steps later minus price two steps earlier": a ramp detector. ReLU then keeps only the up-ramps.

Common confusion. A CNN has no memory; each output depends only on the values under the kernel. Its reach grows only by stacking layers or dilating the kernel. That is why CNNs are usually paired with an LSTM (CNN-LSTM) when long context matters.

Recurrent networks: RNN, LSTM, GRU, BiLSTM

In one sentence. A recurrent network reads the series one step at a time and carries a vector of memory forward, updating it at each step with the new value; an LSTM adds gates that learn what to keep, what to forget and what to output, and a GRU is a lighter version with two gates.

The basic RNN update is ht = tanh(W·xt + U·ht−1 + b): the new memory is a bend of "this input plus the old memory". Its weakness is that the same U is multiplied in at every step, so signals from 50 steps back either vanish or explode. The LSTM fixes this with a separate cell state ct that is edited additively: a forget gate f (0 to 1) scales the old cell, an input gate i scales a proposed new value c̃, and an output gate o decides how much of the cell is exposed as ht. The GRU merges cell and hidden state and uses a reset gate and an update gate. A bidirectional LSTM runs a second copy from the end of the window backwards and concatenates the two memories, which is only legitimate when the whole window is in the past.

Autoencoders: plain, denoising, sparse, stacked (SDAE, SSDAE)

In one sentence. An autoencoder is trained to output its own input through a narrower middle layer, so the middle layer is forced to become a compressed summary; variants change what goes in (noise added) or what the middle is allowed to do (mostly off).

  1. Plain. Encoder squeezes 48 half-hours to, say, 8 numbers; decoder expands back to 48; loss is reconstruction error. The 8 numbers are features.
  2. Denoising (DAE). Random noise (or random zeros) is added to the input, the target is still the clean input. The network can only succeed by learning the structure that survives noise, so its features ignore bid-by-bid jitter.
  3. Sparse. A penalty keeps the average activation of each middle neuron near a small value like 0.05, so on any given input most are off and each active one stands for something specific.
  4. Stacked (SDAE, SSDAE). Train one, freeze it, train a second on the first's middle layer, and so on; then put a regression layer on top and fine-tune the whole stack. Faster and more stable than training a deep network from scratch, which was the point in 2023.

The non-neural baselines: random forest, XGBoost, SVM, ELM

In one sentence. These are the "conventional machine learning" rows in the tables: decision-tree ensembles that split on thresholds, a kernel regression that fits a tube, and a random-feature network.

One regression tree on two features. A random forest averages hundreds of such trees, each grown on a random subset of rows and features. XGBoost grows them one at a time, each fitted to the errors the previous ones left.
  • Random forest (RF). Many trees, each on a bootstrap sample; prediction is the average. Robust, no scaling needed, cannot extrapolate above the largest training price.
  • XGBoost (XGB). Gradient boosting: tree 1 fits the target, tree 2 fits tree 1's residuals, and so on, with regularisation. Usually the strongest tabular baseline; same extrapolation limit.
  • Support vector machine / regression (SVM). Fits the flattest function that keeps most points inside a tube of width ε, using a kernel to allow curves. Scales badly beyond tens of thousands of rows.
  • Extreme learning machine (ELM). A one-hidden-layer network whose hidden weights are random and fixed; only the output weights are fitted by least squares. The RVFL below is an ELM with an added direct input-to-output link.

Random vector functional link network (RVFL)

In one sentence. Take the inputs, push them through a hidden layer whose weights were drawn at random and are never changed, then fit a single linear regression from [inputs, hidden outputs] to the target by least squares; the randomness supplies nonlinearity for free and the least-squares fit takes milliseconds.

"Functional link" is the direct wire from the inputs to the output, so the model is "ordinary linear regression plus random nonlinear extra features". Least squares means solving for the output weights β that minimise Σ(y − Hβ)², which has the closed-form answer β = (HᵀH + λI)−1Hᵀy (λ is a small ridge penalty). No gradient descent, no epochs, no learning rate. In Ghimire 2024 the inputs to the RVFL are the CNN's features, so the "C" in CRVFL is the CNN and the RVFL is the regression head.

Hyperparameter search: grid, random, and Bayesian optimisation

In one sentence. Hyperparameters are the settings you choose rather than train (lags, layers, learning rate, wavelet level); Bayesian optimisation picks the next setting to try by fitting a probabilistic curve to the trials so far and going where the predicted score is high or the uncertainty is wide.

Grid search tries every combination (3 lags × 4 levels × 5 filter counts = 60 trainings). Random search samples combinations at random and is surprisingly competitive because usually only one or two settings matter. Bayesian optimisation keeps a surrogate model, almost always a Gaussian process, which gives a mean and a standard deviation for the score at every untried setting, and an acquisition function such as expected improvement that trades off exploiting good regions against exploring uncertain ones. Typically 20 to 50 trials replace hundreds.

One hyperparameter, six trials done (dots). The purple line is the surrogate's guess, the band its uncertainty. The next trial goes where the upper edge of the band is highest.

Empirical mode decomposition: EMD, EEMD, CEEMDAN, ICEEMDAN

In one sentence. EMD peels a series into a handful of oscillations from fastest to slowest (intrinsic mode functions, IMFs) plus a slow residual, using only the series' own peaks and troughs; the "ensemble" and "adaptive noise" variants fix its habit of mixing frequencies by averaging over many noisy copies.

  1. Find all local maxima and all local minima of the series.
  2. Draw a smooth curve (a cubic spline) through the maxima, another through the minima: the upper and lower envelopes.
  3. Subtract the average of the two envelopes from the series. Repeat ("sift") on the result until what is left oscillates around zero with one peak per zero-crossing. That is IMF1, the fastest component.
  4. Subtract IMF1 from the original and repeat from step 1 to get IMF2, and so on, until the residual has no more oscillations.

Mode mixing: plain EMD often puts two different frequencies in one IMF or the same frequency across two. EEMD adds white noise to the series, runs EMD, repeats a few hundred times with different noise and averages the IMFs; the noise fills in the gaps so components separate cleanly. CEEMDAN adds the noise stage by stage so the IMFs sum back exactly to the series; ICEEMDAN ("improved") adds noise as the EMD of noise rather than raw noise, which removes spurious early modes and leaves less noise in the result. Then each IMF is forecast separately and the forecasts are summed.

Illustrative (a synthetic series, not real sifting): an evening price shape decomposes into bid noise, a daily cycle, and a trend. The slow parts are easy to forecast; the error concentrates in IMF1.
Common confusion. EMD is not a fixed filter; the components depend on the whole series, so an IMF at time t computed on the full dataset has seen the future (see leakage). A causal use must recompute the decomposition on the history available at each origin, which is expensive and is why the review of Tan's paper notes the three-day test windows.

Wavelet transforms: DWT and MoDWT, levels, approximation and detail

In one sentence. A wavelet transform splits a series into a smooth "approximation" and a set of "detail" series, one per scale, using fixed short filters; the ordinary DWT halves the length at each level, while the maximal-overlap DWT (MoDWT) applies the same filters at every time step so every level stays full length and lined up with the original.

The simplest wavelet, Haar, uses the filters "average of two neighbours" (low-pass, gives the approximation A) and "half their difference" (high-pass, gives the detail D). Level 1 applies them to the series; level 2 applies them again to A1; each level doubles the time scale it captures. The number of levels is a hyperparameter (Ghimire chose it by Bayesian optimisation). Longer wavelets (Daubechies db4, symlets) use 4 to 8 coefficients instead of 2 and give smoother components. In the MoDWT the filters are applied at every t instead of every second t, so no information is thrown away and the components can be fed as ordinary aligned input columns.

Common confusion. The MoDWT of the whole test year, computed once, uses the value at t+1 to compute the detail at t for many wavelets (the filter is symmetric or the boundary wraps). That is leakage unless the transform is re-run at each origin on past data only. Neither the Ghimire 2024 abstract nor the review says which was done.

Other decompositions that appear as baselines: SSA, VMD, wavelet-vs-EMD

Singular spectrum analysis (SSA) stacks lagged copies of the series into a matrix, takes its singular value decomposition, and rebuilds the series from the top few components: trend, oscillations, noise. Variational mode decomposition (VMD) solves an optimisation for a fixed number K of band-limited modes with centre frequencies; it is less prone to mode mixing than EMD but you must choose K. Tan 2023 tried wavelet (WT), SSA and EEMD in front of the same CNN+SSDAE and found ICEEMDAN best; the review's table shows wavelet actually made that model worse than no decomposition.

The "decompose, forecast each part, add up" pattern

In one sentence. Split the series into components that are individually smoother than the whole, forecast each with its own model, and sum the forecasts; it works because the summed error is usually less than the error of forecasting the raw series, and it fails when the decomposition itself needs the future.

The template behind Tan 2023 (ICEEMDAN in front, CNN+SSDAE per component), Ghimire 2024 (MoDWT in front, one CNN-RVFL on all components), and a dozen NEM papers not on this page.
Reading the results tables with this in mind
In Tan's table the raw-price CNN+SSDAE has MAPE 8.4 to 9.7 % and the ICEEMDAN version 6.0 to 7.0 %, so the decomposition is worth about 2.5 points. In Ghimire 2024 the wavelet front end lifts every predictor from KGE 0.66 to 0.74 up to 0.90 to 0.97, which is a much larger jump, and the size of that jump is itself a reason to ask whether the components were computed causally.
